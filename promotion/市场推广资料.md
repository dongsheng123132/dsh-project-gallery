# 项目相册 · 市场推广资料

核对日期：2026-11-18（发布后首轮核对）。仓库：https://github.com/dongsheng123132/dsh-project-gallery

## 一句话介绍

项目相册是 DeepSeek Harness 的免费开源插件：把会话里 AI 看过、生成过、交付过的图，以及项目目录里的图，按项目攒成一册；
悬停项目行就能看最近几张，点开能看到**当时你让它做什么**。

English: Project Gallery gathers the images a DSH project has seen, generated or delivered — plus images in the
project directory — into one album per project, with the conversation behind each image.

## 给市场提交的简短介绍

项目做久了，图会散在三处：会话附件、交付目录、项目文件夹。这个插件把三处收进同一本相册，按项目分组；
同一张图在多个会话里出现时，各会话保留各自的上下文。灯箱里图在左、当时那段对话在右，可以直接回答
「这张图是哪次改出来的」。

只读本机文件，不发网络请求，无遥测。零运行时依赖，MIT。目前只在 macOS 上实测（DSH CLI 0.2.2-rc.1、桌面版 0.2.2-rc.3）；
Windows 与 0.3.x 宿主未验证，别替它承诺。
